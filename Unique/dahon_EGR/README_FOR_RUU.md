# Dahon Abre — Evermere Grand Bazaar

Standalone RP profile for **Dahon Abre** (The Verdant Remedy) for the **Evermere Grand Bazaar** group.

## Live URL (main site)

**`/Dahon_EGB`**

Share that path on your deployed site (no `/unique` prefix). Source for the mounted page lives in `src/app/Dahon_EGB/`.

## Art updates

1. Replace `Unique/dahon_EGR/public/dahon_EGB.png` (this folder’s working art)
2. Copy the same file to `public/Dahon_EGB/dahon_EGB.png` so the live page picks it up

Keep the filename `dahon_EGB.png` so links stay valid.

## Season stone icons

Atelier Yumia trait crystal sprites (used as seasonal sun stones on the live page) live in `public/Dahon_EGB/stones/` on the main site:

## Seasonal magic included

The page adds season stones, out of season growing blessings, ripening charms, frost protection, garden wards, and crop preservation magic. These enchantments support a compatible plant but do not eliminate its normal need for climate, light, water, soil, or skilled care.
